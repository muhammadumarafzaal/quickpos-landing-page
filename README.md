# QuickPOS Landing Page Be ready

A beautiful, responsive, single-page landing website for QuickPOS, built with PHP and Vanilla CSS.

## Features
- Modern, clean UI/UX
- Fully responsive design
- Integrated Contact Us form with PHP validation
- Clear product sections (Hero, Features, Pricing)

## Technology Stack
- **Backend**: PHP
- **Frontend**: HTML5, Vanilla CSS, JavaScript
- **Process**: GitFlow, Jira Integration

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/muhammadumarafzaal/quickpos-landing-page.git
   ```
2. Run using a PHP local server:
   ```bash
   php -S localhost:8000
   ```
3. Open `http://localhost:8000` in your browser.

## Jira Integration
Ensure every commit and PR title includes the Jira ticket number (e.g., `[SA-123]`).
